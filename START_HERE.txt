================================================================================
  FOR MOBILE EMULATOR
================================================================================

ANDROID EMULATOR:
1. Install Android Studio: https://developer.android.com/studio
2. Create a virtual device (AVD)
3. In ryt-bank-react folder:
   npm install
   npx cap add android
   
4. Edit src/App.jsx - Change line:
   const API_BASE_URL = 'http://localhost:8000'
   To:
   const API_BASE_URL = 'http://10.0.2.2:8000'
   
5. Build and run:
   npm run build
   npx cap sync android
   npx cap open android
   
6. In Android Studio, click the green Run button

iOS SIMULATOR (Mac only):
1. Install Xcode from Mac App Store
2. In ryt-bank-react folder:
   npm install
   npx cap add ios
   
3. Get your local IP:
   ifconfig | grep "inet "
   
4. Edit src/App.jsx - Change line to your IP:
   const API_BASE_URL = 'http://YOUR_IP:8000'
   
5. Build and run:
   npm run build
   npx cap sync ios
   npx cap open ios
   
6. In Xcode, select simulator and click Play

================================================================================
  TROUBLESHOOTING
================================================================================

"Cannot connect to server"
→ Make sure START.bat is running (backend server)
→ For Android emulator, use http://10.0.2.2:8000
→ For iOS simulator, use your local IP address

"npm install fails"  
→ Make sure Node.js is installed: https://nodejs.org
→ Clear cache: npm cache clean --force
→ Try again: npm install

"Module not found"
→ cd ryt-bank-react
→ npm install
→ npm run build

"Android/iOS build fails"
→ Make sure Android Studio (or Xcode) is installed
→ Create virtual device first
→ Try: npx cap sync --force
